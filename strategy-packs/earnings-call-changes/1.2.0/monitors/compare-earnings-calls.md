# Compare selected earnings calls

Call `evaluate_earnings_call_changes` exactly once for this occurrence. Do not
fetch transcript URLs or stage a separate finding. Report the capability's
bounded status; a prose response does not complete the occurrence.

One occurrence runs the shared worker session, the bounded transcript
comparison child, and - only when the comparison already produced a material
cited change - one bounded frontier research child that commits the executive
brief. A no-change occurrence never reaches the research child and spends
nothing on it.

Versions up to 1.1.0 signed the comparison session at the policy envelope's
24,000 aggregate input tokens. A real reviewed transcript pair measures about
59,000 estimated input tokens, so every real pair overflowed the planner and
abstained without being analyzed. This version signs one comparison job at
96,000 input and 12,000 output tokens, which holds a real pair with headroom for
a longer call, and reserves 200,000 input and 48,000 output tokens per run to
cover the worker session, that comparison, and the research child together.
