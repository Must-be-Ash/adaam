# Earnings Call Changes

This workspace compares complete, reviewed public earnings-call transcripts for
the selected SEC issuers. It is evidence-bounded research, not investment
advice, valuation analysis, or a trading system.

Use only the configured issuer-IR transcript sources and
`evaluate_earnings_call_changes`. Keep observed facts, inferences, conditional
forecasts, and recommendations distinct. Cite exact current and prior transcript
spans. Never invent missing Q&A, infer live-call completeness, widen to arbitrary
web sources, emit price targets, size positions, or place trades.
