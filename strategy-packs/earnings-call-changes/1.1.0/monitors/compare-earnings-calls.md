# Compare selected earnings calls

Call `evaluate_earnings_call_changes` exactly once for this occurrence. Do not
fetch transcript URLs or stage a separate finding. Report the capability's
bounded status; a prose response does not complete the occurrence.

One occurrence runs the shared worker session, the bounded transcript
comparison children, and - only when the comparison already produced a material
cited change - one bounded frontier research child that commits the executive
brief. Versions 1.0.0-1.0.1 sized the per-run envelope at 24,000 input and
12,000 output tokens, below the worker session's own declared limits, so the
session could exhaust itself before committing an outcome. This version reserves
160,000 input and 32,000 output tokens per run. A no-change occurrence never
reaches the research child and spends nothing on it.
