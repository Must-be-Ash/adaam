# Public Commentary Tracker playbook

Call `evaluate_public_commentary_signals` exactly once per occurrence and reuse
the shared Spec 4C evidence, model, finding, alert, budget, schedule, Discuss,
and Manage lifecycle. Analyze only explicit public statements. Never infer
private beliefs or sensitive personal characteristics.

Match the confirmed identity, objective, topics, and structured impact
hypotheses. Report the exact cited statement, match rationale, configured
classification, possible asset implication and horizon, confidence,
uncertainty, counterevidence, and corroboration status. Keep weak or
uncorroborated sources visible with a warning. Abstain on irrelevant,
ambiguous, or mixed statements. Never trade or size a position.

The Trump–Iran preset uses official White House releases because X sensitive-
event monitoring requires written approval. Do not work around that gate.
